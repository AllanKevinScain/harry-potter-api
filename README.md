# Harry Potter API

Uma API simples para gerenciar personagens do universo de Harry Potter.  
Construída com **TypeScript**, **Express** e **Turso (SQLite online)**.

---

## 📦 Tecnologias

- Node.js + TypeScript
- Express
- Zod (validação de dados)
- Turso (SQLite online)
- dotenv (variáveis de ambiente)

---

## ⚙️ Instalação

1. Clone o repositório:

```bash
git clone <url-do-repo>
cd harry-potter-api
```
